# Frenzy

Simple website booking application that made use of Firebase Realtime Database and Google Calendar API to store and show the latest user reservations remotely and easily through the Google Calendar Apps.

The frontend part is entirely made with pure HTML, CSS, and JavaScript as part of a learning process to understand the underlying basics of frontend website development. Some libraries such as [FullCalendar](https://fullcalendar.io/) are used to sped up the development process as the project was made during my school internship, as it was near the end of the internship program and I have to prepare for the end of program documentations.
